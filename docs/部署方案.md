# 智能报价系统 — 部署方案

> 适用场景：在一台**没有任何依赖**的电脑（Windows 或 macOS）上部署本系统。
> 部署完成后，Windows 双击 `启动.bat`、macOS 双击 `启动.command` 即可运行，
> 浏览器访问 http://localhost:3000。

---

## 〇、macOS 部署

### 1. 安装运行环境

```bash
brew install node python     # Node.js 22+ 与 Python 3.11+
node -v                      # 应显示 v22.x 或更高
python3 --version            # 应显示 3.11+
```

（未安装 Homebrew 的话，也可分别从 https://nodejs.org/ 和 https://python.org/ 下载安装包。）

### 2. 解压部署包

解压到任意目录（如 `~/智能报价系统/`），确认包含：

- `启动.command`
- `data/quote_saitel.db`（系统默认库）
- `demo-app/`（前后端源码）

### 3. 启动与停止

- **启动**：双击 `启动.command`。首次运行会自动创建虚拟环境 `demo-app/backend/.venv`、
  安装 Python 依赖和前端 `npm ci`（需联网，约 2-5 分钟），随后后台启动后端（8000）
  与前端（3000）并打开浏览器。
- **停止**：双击 `停止.command`。
- **日志**：`data/backend.log`、`data/frontend.log`。

> 说明：Homebrew 的 Python 启用了 externally-managed 限制，不能直接向系统目录装包，
> 因此 mac 版统一使用 `.venv` 虚拟环境，与 Windows 版的全局安装不同。

> 如果首次双击提示"无法验证开发者"：「系统设置 → 隐私与安全性」点"仍要打开"，
> 或右键文件选择「打开」。

### 4. macOS 常见问题

| 问题 | 解决方法 |
|------|---------|
| `pip install` 报 `externally-managed-environment` | 必须用虚拟环境：`.venv/bin/pip install -r requirements.txt` |
| 双击 `启动.command` 一闪而过 | 终端手动执行 `zsh 启动.command` 查看报错 |
| 端口被占用 | `lsof -iTCP:3000 -sTCP:LISTEN` / `lsof -iTCP:8000 -sTCP:LISTEN` 找到进程后 `kill` |

## 一、部署前检查

目标机器要求：

- **操作系统**：Windows 10 / 11（64 位）
- **网络**：部署期间需要联网（下载安装包和依赖）
- **权限**：安装软件时需要管理员权限

## 二、安装运行环境（仅需一次）

### 1. 安装 Node.js 22 或更高版本

1. 打开官网 https://nodejs.org/ ，下载 **LTS（长期支持版）** 的 Windows 安装包（`.msi`）
2. 双击安装，**一路默认即可**（安装程序会自动加入 PATH）
3. 验证：打开一个新的命令提示符（Win+R 输入 `cmd` 回车），执行：

   ```
   node -v
   ```

   显示 `v22.x.x` 或更高版本即成功

### 2. 安装 Python 3.12 或更高版本

1. 打开官网 https://www.python.org/downloads/ ，下载 Python 3.12+ 的 Windows 安装包
2. **重要**：运行安装程序时，第一个界面务必**勾选最下方的 "Add python.exe to PATH"**，然后点 "Install Now"
3. 验证：新开一个命令提示符，执行：

   ```
   py --version
   ```

   显示 `Python 3.12.x` 或更高版本即成功

> 说明：本系统统一使用 `py` 启动器调用 Python，可避开 Windows 应用商店占位程序的干扰，安装 Python 时会自动带上 py 启动器，无需额外操作。

## 三、部署系统本体

1. 从云端下载部署包 `智能报价系统_部署包.zip`
2. 解压到本机任意目录（如 `D:\智能报价系统\`）
   - 建议路径不要过长，避免个别工具的路径长度限制
3. 确认解压后的目录包含：
   - `启动.bat`
   - `data\quote_saitel.db`（**系统默认库**：既是赛特尔25年价目数据，也是用户/客户/报价任务的存放处；程序固定读这个目录，与启动时的当前目录无关）
   - `demo-app\`（前后端源码）

## 四、启动系统

**双击 `启动.bat`**，脚本自动完成：

1. 检查 Node.js 和 Python 环境
2. 安装后端 Python 依赖（首次约 1-2 分钟）
3. 安装前端依赖 `npm ci`（首次约 1-3 分钟，视网络情况而定）
4. 启动后端 API（端口 8000）和前端（端口 3000）

启动完成后按任意键关闭主窗口（不影响运行），浏览器访问：

```
http://localhost:3000
```

| 角色 | 用户名 | 密码 |
|------|------|------|
| 管理员 | admin | admin123 |
| 报价员 | quote | quote123 |

首次启动之后，日常使用时双击 `启动.bat` 会跳过已装好的依赖，十几秒内即可完成启动。

## 五、日常使用说明

- **三个窗口**：主启动窗口启动完成后可关闭；"报价系统-后端"和"报价系统-前端"两个窗口最小化保留即可，关掉对应服务就停止
- **停止系统**：关闭"报价系统-前端"和"报价系统-后端"两个窗口
- **数据备份**：备份整个 `data\` 目录即可（报价记录、客户、账号、价目数据全在里面）

## 六、常见问题（FAQ）

| 问题 | 解决方法 |
|------|---------|
| 双击启动.bat 提示"未检测到 Node.js" | Node 未安装或未加入 PATH，重装 Node.js 并确认 `node -v` 有输出；安装后需新开命令窗口再试 |
| 提示"未检测到 Python" | 重装 Python，安装时勾选 "Add python.exe to PATH"；验证 `py --version` |
| `npm ci` 报错 | 确认 Node.js ≥ 22（`node -v`）；确认网络通畅；关掉杀毒软件/360 后重试 |
| `pip install` 报错 | 确认 Python ≥ 3.12（`py --version`）；确认网络通畅 |
| 浏览器打不开 localhost:3000 | 确认"报价系统-前端"窗口还在运行；3000 端口是否被其他程序占用（见下方"端口占用排查"） |
| 页面能打开但提示连接后端失败 | 确认"报价系统-后端"窗口还在运行；8000 端口是否被占用 |
| 命令行输入 python 弹出微软商店 | 正常现象（商店占位程序），本系统统一使用 `py` 命令，无需理会 |
| 端口被占用排查 | 管理员身份运行命令提示符，执行 `netstat -ano \| findstr ":3000"` 和 `netstat -ano \| findstr ":8000"`，找到占用进程后结束它，或修改端口后重启 |

## 七、手动启动（备选方案）

如启动.bat 出现问题，可手动开两个命令提示符窗口：

**窗口 1 — 后端：**

```
cd demo-app\backend
py -m pip install -r requirements.txt
py -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

**窗口 2 — 前端：**

```
cd demo-app
npm ci
npm run dev
```

浏览器访问 http://localhost:3000

## 八、卸载

删除整个系统目录即可，无注册表残留。
如需彻底清理运行环境，可在"设置 → 应用"中卸载 Node.js 和 Python。
