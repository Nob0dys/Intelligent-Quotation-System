## 一、系统是什么

面向教学仪器采购的**智能报价系统**：上传采购清单 Excel → 自动逐行匹配历史价目库 → 生成多方案报价 → 人工复核确认 → 一键导出客户版/内部复核版。

**核心价值**：把"逐行翻价目本"变成"自动带价 + 人工把关"，报价员只需处理系统标出的少数待复核行。

## 二、启动方法

```powershell
# 后端（工作目录必须是 backend）
cd E:\东方理工\智能报价系统_完整代码包\demo-app\backend
$env:DATABASE_URL = "sqlite:///./data/quote_saitel.db"   # 赛特尔-only 库（交付用）
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- 健康检查：`http://127.0.0.1:8000/api/health` → `{"status":"ok"}`
- 前端：`http://localhost:3000`（如已构建）
- 默认账号：`admin / admin123`（管理员）、`quote / quote123`（报价员）

## 三、使用流程（5 步）

### 第 1 步：上传采购清单
- 支持 `.xlsx / .xlsm / .xls`，自动识别表头（品名/规格/单位/数量/编码）
- 支持多 sheet、多段表头、公式数量列

### 第 2 步：自动匹配（后台秒级完成）
系统对每行做：
1. **候选池**：类目硬过滤（JY 编码大类 + 名称关键词类目）→ 名称/规格相似度排序取前 250
2. **打分**：参数 40 + 型号 13 + 名称 13 + 制造商 9 + 单位 9 + 数据质量 4 + 类目 6 + 价格一致性 6 + 时效
3. **默认选中**：赛特尔优先 → 老编号体系（初中物理/高中物理 5 位 JY 码）优先于新课标（13 位码）→ 同核心词×价位簇去重
4. **守卫**：价格翻倍守卫（偏离同组中位数 >2x 不默认选）、规格变体罚（数显/指针/量程）、修饰词变体罚（演示≠实验 除外）

### 第 3 步：人工复核（重点看 3 类行）
- **待复核清单**（内部版导出自带）：估算价行、低置信行、BLOCK 行
- 每行显示 `suggested_action` 推荐操作：可直接确认 / 复核估算价 / 低置信复核 / 阻断复核 / 手工建方案
- 可改价、换方案、手工新建方案（无历史时）

### 第 4 步：确认
- 单行确认 / 批量确认（仅 high 置信 ≥80 分且无 BLOCK）
- **确认价自动回写草稿**（`confirmed_price_drafts` 表），管理员审核后进入历史库 → 越用越准

### 第 5 步：导出
- **客户版**：只含报价列（确认单价/税后单价/总价/税后总价/品牌/制造商/型号/编码）
- **内部复核版**：+ 匹配状态/匹配分/风险提示/历史来源 + 待复核清单 sheet
- **多厂商对照**（2026-09-27 起）：任务方案数 >1 且选中多方案时，按 `报价1/报价2/报价3` 列组输出，每组含 `单价/制造商/品牌/型号/产品编码/规格`；厂商次序按其在价目库中的首现顺序固定（如 XJHY 库 赛特尔→瑞仕达→德欧），重复导出结果一致
- **型号列口径**：产品编码缺失时回填历史记录的型号字段（XJHY 库的 11 位课标编码存在型号列）
- **宽表价目本直导**：`品牌1/厂家1/型号1、品牌2/…` 同行的价目本（如副本XJHY数据库）导入时自动拆成多厂商记录，无需离线转换
- 税率任务级可调（默认 10%）

## 四、演示要点（浙江三和案例）

**演示脚本**（约 10 分钟）：

1. **上传** `测试数据\浙江三和初中物理仪器0309 - 空白本.xlsx`（63 行）
2. **展示匹配结果**：63 行全部自动带价，0 行需人工介入
3. **重点展示 3 个"精确命中"**（此前模糊匹配会错的）：
   - 摩擦力演示器 → **220 元**（高中物理 21024）
   - 压力和压强演示器 → **9 元**（初中物理 21021，老编号优先于新课标 22 元）
   - 立体磁感线演示器 → **75 元**（初中物理 24004）
4. **导出** 内部复核版 + 客户版，展示列结构
5. **口径说明**（重要，避免误解）：
   - 系统按"产品身份 + 价格量级"匹配，客户验收口径 ±30% 内算正确
   - 浙江三和 63 行中 60 行命中（客户已确认 68 错 3 口径下仅 3 行偏差）

**已生成样例**：`报价测试输出\赛特尔only_浙江三和_内部复核版_最终.xlsx`、`客户版_最终.xlsx`

## 五、关键规则速查

| 规则 | 说明 |
|---|---|
| 赛特尔优先 | 有赛特尔25年记录时默认选赛特尔 |
| 老编号优先 | 初中物理/高中物理（5 位 JY 码）> 初中新课标物理（13 位码） |
| 演示器=实验器 | 摩擦力演示器 = 摩擦力实验器，等价不罚 |
| 包装单位互换 | 套↔盒↔包↔箱 可换算不 BLOCK |
| 价格守卫 | 偏离同核心词组稳健中位数 >2x 不默认选中 |
| 估算价兜底 | 无匹配时按类目第 10 分位价生成保守估算，标"需人工复核" |
| 确认回写 | 人工确认价自动进草稿队列，审核后入历史库 |

## 六、注意事项（交付时务必知晓）

1. **评测口径**：系统"精确价格相等"口径下浙江三和约 51%；客户"±30% 量级"口径下约 95%。汇报时务必说明口径，避免数字误解。
2. **库的选择**：交付用 `quote_saitel.db`（赛特尔定制价目本）。若客户要求全量历史（包1-4/普教），切 `quote_test.db` 并重新跑任务。
3. **标准答案文件**（浙江三和0309.xlsx、琼侨清单.xls）**不要导入历史库**，否则评测会"用答案考自己"。
4. **琼侨任务**：标准答案按 2020 版（3.19 海口）价格，与赛特尔25年存在版本差，匹配率天然偏低（约 35%），属正常，非系统缺陷。
5. **前端**：本轮改动全在后端 API；若演示需要界面，先 `npm run build` 并启动 Next.js。
6. **测试**：`python -m pytest tests/` 50/50 通过（含浙江三和/琼侨回归基准）。

## 七、常见问题

| 问题 | 处理 |
|---|---|
| 上传后一直 queued | 检查 worker 是否运行（`python -m app.worker` 或重启 uvicorn） |
| 某行无候选 | 库中无此产品 → 手工建方案，确认后自动回写 |
| 价格明显不对 | 查看该行"风险提示"（价格偏离/规格变体/单位换算） |
| 想换历史库 | 停服务 → 改 `DATABASE_URL` → 重启 → 重新上传任务 |
| 导入新价目本 | 管理员 → 历史库导入（支持 .xlsx/.xls，自动去重、含税折回） |
