# 智能报价系统（Intelligent Quotation System）

基于历史采购价目库的实验教学仪器自动报价系统：上传采购清单 Excel，系统自动匹配历史价目、生成多制造商候选方案，复核后导出客户版 / 内部复核版报价单。

## 功能概览

- **报价任务**：上传询价单（.xlsx / .xlsm / .xls / .csv）→ 自动匹配历史价目 → 人工复核 → 一键导出
- **多厂商报价**：每个产品可输出最多 5 个不同制造商的候选方案（导出为 报价1~报价N 列组）
- **价目库管理**：多库并存，新建/重命名/删除/导入价目本，表格化编辑、质量治理、审计留痕
- **任务级绑定**：每个报价任务显式绑定所用价目库，互不干扰

## 技术栈

- 前端：React 19 + vinext（Vite）+ Tailwind CSS 4，开发服务器代理 `/api`
- 后端：FastAPI + Uvicorn + SQLAlchemy + SQLite（每库独立 `.db`，数据目录按包根解析）
- 测试：后端 pytest 123 个用例；前端 TypeScript 严格编译

## 快速开始

### Windows

1. 安装 Node.js 22+ 与 Python 3.12+（安装时勾选 Add to PATH）
2. 双击 `启动.bat`：自动装依赖、起后端（127.0.0.1:8000，仅本机）与前端（0.0.0.0:3000，局域网可访问）
3. 启动完成后脚本会显示「本机访问」与「局域网访问」地址；浏览器打开 http://localhost:3000

### macOS

1. `brew install node python`
2. 双击 `启动.command`（自动创建 `.venv` 虚拟环境，Homebrew Python 必需）；停止用 `停止.command`

登录默认账号：admin / admin123（管理员）、quote / quote123（报价员）。

## 目录结构

```

│   └── backend/tests/        # pytest 用例
├── docs/                     # 交付/部署/使用文档
└── 测试数据/                  # 测试夹具（真实询价单，供 pytest 复现用例）
```

## 2026-09 更新摘要

- **macOS 部署适配**：新增 `启动.command` / `停止.command`（venv 自动创建、后台服务、自动开浏览器），文档补充 macOS 章节
